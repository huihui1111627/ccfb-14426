# 流水线并行训练调度器

古桥巡检裂缝/风化识别模型的流水线并行训练模拟：模型用固定种子初始化的 MLP 代替，
每张卡一个协程模拟，支持三种调度并带可视化页面。

## 结构

- `internal/pipe/` — 核心包
  - `model.go` — 确定性 MLP（固定种子初始化、固定顺序梯度累加，保证逐位可复现）
  - `schedule.go` — 三种调度生成器：GPipe（全前向-全反向）、1F1B（一前一后）、交错（虚拟段）
  - `sim.go` — 事件驱动模拟器：每张卡一个协程，卡间传输时延与各卡算力可配
  - `theory.go` — 气泡占比与峰值激活的理论公式
  - `train.go` — 单卡基线训练与流水线训练（梯度按微批固定顺序累加，逐位一致）
  - `validate.go` — 逐条检查每个前向/反向的依赖关系
- `cmd/server/` — 可视化页面（时序图、气泡占比、峰值激活、各调度耗时对比、慢卡场景）
- `cmd/demo/` — 慢卡场景耗时对比的命令行版本

## 运行

```sh
go test ./...          # 随机组合逐位一致 + 依赖检查 + 理论值核对 + 慢卡场景
go run ./cmd/server    # 打开 http://127.0.0.1:8080
go run ./cmd/demo      # 慢卡场景耗时对比表
```

## 理论值

| 调度 | 气泡占比 | 峰值激活（第 d 卡） |
|---|---|---|
| GPipe | (p-1)/(m+p-1) | m |
| 1F1B | (p-1)/(m+p-1) | min(p-d, m)，在飞微批 ≤ p |
| 交错 (v 段) | 1 - m·v/max(m+p·v-1, m·v+p-1) | m·v（段激活单位） |

梯度按微批下标固定顺序累加，三种调度训练任意步后的参数与单卡训练逐位一致
（`TestBitwiseRandomCombos` 覆盖 48 种随机的 层数×卡数×微批数×虚拟段数 组合，
含不整除情形与慢卡/传输时延）。
